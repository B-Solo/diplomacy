# Classic Map Provenance

## Variant

This is the seven-player standard Diplomacy map, with 75 playable provinces,
19 sea spaces, and the usual split coasts for Bulgaria, Spain, and St
Petersburg. It is intentionally unlabelled so names, anchors, supply centres,
powers, and the starting setup can be configured in the map editor.

## Sources

- [Wikimedia Commons standard-map reference](https://commons.wikimedia.org/wiki/File:Diplomacy.svg)
- [elespike/diplomacy_maps printable SVG](https://github.com/elespike/diplomacy_maps/blob/master/Diplomacy.svg),
  a cleaned and print-oriented derivative of the Wikimedia map
- [GoDip classical map SVG](https://github.com/zond/godip/blob/master/variants/classical/svg/map.svg),
  used as an additional gameplay-map comparison
- [Official Hasbro Diplomacy rules](https://www.hasbro.com/common/instruct/diplomacy.pdf)
- `vendor/diplomacy/diplomacy/maps/svg/standard.svg`, the detailed standard
  map distributed with the vendored `diplomacy` 1.1.2 adjudicator
- `vendor/diplomacy/diplomacy/maps/standard.map`, the matching province,
  adjacency, supply-centre, and starting-position data

`map.yaml` is a best-effort standard 1901 setup generated by
`tools/generate_classic_map_yaml.py`. Its powers, home centres, neutral centres,
and initial units follow the published standard rules and starting-position
reference; review anchors and colours in the editor before a live game.

The province outlines use the vendored GoDip classical map SVG. GoDip is
licensed under GPL-3.0; the unmodified source and its full licence are retained
in `vendor/godip/`. The printable map by Martin Asal and Eric Spiker remains
vendored as an independent reference under CC BY-SA 4.0, with its SVG metadata
and adjacent `LICENSE.md` retaining attribution and licence. The earlier jDip
map also remains vendored under its own licence.

## Reconstruction

Run `tools/reconstruct_classic_map.py` to regenerate `map.svg`. The script
extracts GoDip's semantic paths for all 75 spaces rather than retracing a
raster image. These detailed paths provide coincident shared edges, accurate
coastlines and islands, and one uniform 1.6-unit stroke everywhere. It expands
province identifiers to stable `territory-<name>` groups with explicit
`data-territory-kind` values and retains Switzerland, impassable islands, the
natural Danish straits and Bosporus, and a narrow Kiel canal as non-playable
terrain details.

Each detail uses `data-map-fill="sea"` or `data-map-fill="inaccessible"` so it
keeps the map presentation's terrain colour when the containing province is
recoloured. Detail geometry is excluded from inferred province adjacency.
